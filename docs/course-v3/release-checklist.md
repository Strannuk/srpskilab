# Редакторские ворота качества перед выпуском урока

- [ ] Сохранён прежний ID и зафиксирован `content_version`.
- [ ] Уникальный результат `canDo` обеспечивается теорией и независимо проверяется практикой.
- [ ] Нет полных дублей диалога, теории и контрольного набора.
- [ ] Новые слова и грамматика отработаны до контроля; повторная лексика не выдаётся за новую.
- [ ] Не менее одного задания не сводится к угадыванию готового ответа.
- [ ] Человек-редактор подтвердил соответствие сербской норме и корректный русский перевод.
- [ ] Опубликованные аудио воспроизводятся, произношение проверено и права распространения выяснены.
- [ ] Проверены сборка, тесты, RLS и синхронная версия вопросов клиента/серверного банка.
- [ ] Проверены переходы в соседние уроки, старая история прогресса не потеряна.
- [ ] Проведён учебный пилот на целевой аудитории и замечания исправлены.
- [ ] Владелец разрешил публикацию. Нельзя автоматически отправлять draft в production.

**Для всех 20 черновиков A0 ни один пункт человеческой экспертизы и production-разрешения пока не утверждён.**
