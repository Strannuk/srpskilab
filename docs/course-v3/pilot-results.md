# Пользовательские пилоты

Реальные пилотные исследования **не проводились**. Пока нет данных о достижении результата учащимися: техническая проверка JSON не заменяет учебный эксперимент.

Для первого пилота m1l1 (в дальнейшем те же критерии применять к другим 19 черновикам A0) потребуется 3–5 русскоязычных начинающих с разным опытом: пройти урок без помощи, попытаться написать 10 слов кириллицей, распознать новую надпись в магазине, описать ошибки и проверить, запомнили ли они соответствия через 1–3 дня. Отдельно — проверка сербоязычным специалистом, особенно аудио. Данные реальных людей публиковать только в обезличенном агрегированном виде с разрешением.
