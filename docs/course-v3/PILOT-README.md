# Первые двадцать черновых уроков A0 m1l1–m4l5 — запуск и границы

**Запуск в VS Code:** `npm ci` → `npm run dev` → открыть **http://localhost:5173/pilot/m1l1** … **http://localhost:5173/pilot/m4l5**, а для просмотра всех целей — **http://localhost:5173/editorial/curriculum**. Маршрут специально существует только при `import.meta.env.DEV`; при production-сборке не выдаётся как доступная страница. Аудиофайлы подгружаются исключительно из локального Vite middleware `/__pilot_audio/*`, никогда не копируются в `dist`.

- Это двадцать самостоятельных учебных черновиков по письменности, знакомству, числам и бытовым диалогам: теория, 10 слов, самостоятельная запись всех 10 без выбора вариантов, новый разговор, слуховая задача с сокрытым транскриптом, 5 управляемых упражнений, 7 итоговых задач, личная практика и домашняя работа.
- Ответы в пилоте **не отправляются** в Supabase, `content_version=2` относится только к черновику. Старый `m1l1` остаётся в каталоге `src/content/catalog.json`, его 7 вопросов и SQL question bank **не менялись**, `completed` пользователя не изменён.
- Для нового материала создана собственная папка **editorial/pilot-audio**, исключённая из Git через `.gitignore` с 364 синтетическими демонстрационными записями eSpeak. Каждая дорожка технически декодируется, но фонетическое качество, лицензия распространения и естественность произношения **не проверены человеком**. Не публиковать этот пакет без такой проверки.
- Пилот имеет две независимые проверки: 10/10 слов кириллицей и локальный тест ≥70%. Даже оба успеха не означают официальный зачёт или проверку произношения.
- На последующих этапах нужно: (1) экспертно проверить материал и звук, (2) разработать API/контракт LessonV3, (3) синхронно изменить версии клиентских вопросов и серверного `private.lesson_question_bank`, (4) обеспечить откат, (5) провести тест с учащимися и только после этого разрешить отдельный production-релиз.

## Что не было сделано

Содержание оставшихся 245 уроков **не переписано**. Их 245 плановых паспорта — предложенные индивидуальные цели и сырой лексический реестр, а не утверждённые грамматические/языковые сценарии. Нет доступа к боевой базе или её данным. Нет пилотной проверки учениками или носителем.

**При обновлении из Git:** после клонирования нужно локально выполнить `npm run audio:v3:pilot` (требуются установленные программы `espeak` и `ffmpeg`). В скачиваемом архиве для локального просмотра файлы приложены, но в Git не должны попадать до проверки лицензии.
