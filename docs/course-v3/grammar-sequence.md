# Карта последовательности грамматики (на утверждение)

Эта карта **проектная**, заимствована по смыслу из `content-spec.md` §8; она не свидетельствует о наличии перечисленных тем в 265 существующих уроках.

| Уровень | Что должно быть освоено | Чем подтвердить |
|---|---|---|
| A0 | Две азбуки, звуки, приветствия, минимальные местоимения, формы biti, простой вопрос, цифры/даты | Новое короткое чтение, отдельные слова и простая вежливая реплика |
| A1 | Род, число, согласование, настоящее время, простые предлоги, притяжательность, начальный винительный | Простая бытовая просьба, краткий диалог с собственным ответом |
| A2 | Семь падежей с функциями, времена, возвратность, модальность, просьбы, сравнение, движение | Реальная бытовая проблема и короткое письменное сообщение |
| B1 | Вид глагола, управление, клитики, связность и условные конструкции | Связный рассказ, аргумент и самостоятельное письмо |
| B2 | Сложные связи, оттенки вида, регистр, логический акцент, публичное обсуждение | Неподготовленная дискуссия и жанрово корректная аргументация, отдельно с внешней проверкой |

Нельзя утверждать «CEFR B2 достигнут» на основании компьютерных тестов без проверки свободного аудирования, письма и устного взаимодействия. При составлении каждого урока редактор должен указать, **где впервые вводится** соответствующая конструкция, её предпосылки и отложенное повторение. Черновые определения во всех 265 паспортах ещё предстоит проверить методисту и специалисту по сербскому.
