# Озвучка — критерии допуска к публикации

Пилотные 364 файла лежат в `/editorial/pilot-audio`, манифест помечен `UNREVIEWED_DEMO_ONLY`. Они подготовлены eSpeak Serbian исключительно для внутреннего прототипа и не считаются проверенными образцами произношения. **Права распространения аудио и корректность ударения ещё не подтверждены.**

Для каждого отдельного `audioId`: проверить точное соответствие словам и их склонению, отсутствие обрезаний, разборчивость, екавскую норму и корректное произношение J, C, Č/Ć, Đ/Dž, Lj/Nj, длительность/шум; записать статус и человека, проводившего проверку. В отдельном аудировании текст до ответа скрыт, только после попытки доступен транскрипт. Тестировать на Android/Chrome, iOS/Safari, Windows/Chrome; учитывать autoplay и отключённый звук. Все новые аудиофайлы должны быть лицензированы для нужного вида публикации. При отсутствии разрешения урок остаётся черновиком.

Папка редакторских демонстрационных MP3 исключена из Git. Vite раздаёт её через dev-only middleware `/__pilot_audio`; Cloudflare Workers никогда не получают эти файлы из `public/`. Отсутствие публикации уменьшает риск, но сама генерация не подтверждает прав на распространение.
