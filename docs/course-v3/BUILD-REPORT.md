# Отчёт о выполненных технических проверках (пилот v3)

- **Успешно:** проверка TypeScript командой `node node_modules/typescript/bin/tsc -b` на локально извлечённых зависимостях.
- **Успешно:** `node scripts/build-syllabus-v3.cjs` — 265 плановых паспортов сопоставлены со 265 старыми ID и 31 модулем.
- **Успешно:** `node scripts/audit-course-v3.cjs` — аудит дублей; 31 уникальная группа диалогов в старом каталоге.
- **Успешно:** `node scripts/validate-pilot-v3.cjs` — 20 учебных черновиков, 200 письменных соответствий, 140 проверочных вопросов, проверка 364 локальных синтетических MP3 с `ffprobe`; публичный старый урок не заменён.
- **Успешно:** `node scripts/verify-content.cjs` — проверка исходного публичного каталога после исправления старой ошибки (публичные вопросы не содержат секретных ответов).
- **Успешно:** `python scripts/check-audio.py` — 1235 ссылок старого аудиоманифеста и выборочная декодируемость 32 файлов.
- **Невыполнено:** `vite build`, Vitest/E2E в этом контейнере: вложенные в исходный пользовательский RAR бинарные зависимости были установлены под Windows, а Linux-бинарник `@rollup/rollup-linux-x64-gnu` отсутствует; сетевой npm не смог загрузить новые бинарники. Это ограничение тестовой среды, **не доказательство**, что сборка в Windows корректна. После применения патча на Windows обязательно выполнить `npm ci`, `npm run build` и `npm run test`.
- **Не проводились:** запуск реального Supabase, Cloudflare production, проверка RLS, реальный пользовательский пилот, экспертная фонетика/лицензирование новых демо MP3. Серверная миграция нового банка ответов не подготовлена к применению, так как редакторский этап не завершён.

**Готовность:** технически проверенные **локальные редакторские черновики** первых 20 уроков A0; не релиз SrpskiLab 3.0.

- **Успешно:** реконструкция оригинального **закрытого** банка ответов из старых исходных данных с полной сверкой всех 1855+100 публичных формулировок, вариантов и ID; подготовлен отдельный guarded SQL для пустой базы (не применялся).
- **Разграничение:** только 20 рукописных черновиков A0. 245 уроков по планам остаются не написанными; лицензия и профессиональная фонетическая/педагогическая проверка отсутствуют.
