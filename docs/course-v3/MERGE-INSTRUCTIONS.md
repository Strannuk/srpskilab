# Перенос редакторских материалов SrpskiLab v3 в свой GitHub (Windows / VS Code)

**Текущий пакет:** 20 полных учебных **черновиков** A0 (m1l1–m4l5) и 265 индивидуальных **планов**, а не готовых уроков A0–B2. Работающая production-версия 2.1 остаётся нетронутой.

1. Сохрани оригинальный Git-репозиторий и его `.env.local`, проверь `git status`. Создай от свежей основной ветки отдельную ветку `feature/course-v3-editorial` (`git switch -c feature/course-v3-editorial`).
2. Распакуй `SrpskiLab-v3-A0-20-drafts.zip` **в другую папку**, открой её в VS Code. Не копируй `.git` и `.env.local` и не заменяй автоматически более новые файлы собственного репозитория. Переноси изменения только после сравнения diff; при необходимости перенеси весь рабочий каталог как основу отдельной Git-ветки, но сохрани имеющиеся локальные настройки.
3. В PowerShell внутри редакторской папки: `npm ci`, `npm run typecheck`, `npm run content:verify`, `npm run content:v3:validate`, `npm run test`, `npm run build`, `npm run dev`. Если FFmpeg установлен, `ffprobe` проверит техническую длительность всех демо MP3; без него валидатор сообщит, что проверял только наличие файлов.
4. Открой `http://localhost:5173/pilot/m1l1` ... `http://localhost:5173/pilot/m4l5`, а также `http://localhost:5173/editorial/curriculum`. Просмотр работает **только в dev-режиме**. Демо-аудио приложено в ZIP, но `.gitignore` не позволяет отправить его на GitHub. Если после свежего клонирования его нет, понадобится локальная перегенерация через `espeak` и `ffmpeg` либо собственные проверенные дорожки.
5. В Supabase **не меняй** результаты пользователей, `content_version` и серверный банк ответов ради включения этих 20 черновиков. Оригинальный курс всё ещё использует прежние вопросы. Прежде чем что-либо менять, выполни запросы из `supabase/checks/read-only-healthcheck.sql` и прочитай `MANUAL-SETUP-RU.md`.
6. Отправляй только ветку разработки: `git add .`, `git commit -m "feat: editorial A0 drafts and 265 plans"`, `git push -u origin feature/course-v3-editorial`. **Не мержи в `main`** до ручной проверки аудио, сербского языка и серверной совместимости.

**Безопасность:** `.env.local`, `.env`, `.git`, `node_modules`, `dist`, закрытый банк ответов `supabase/private` и production-ключи НЕ входят в архив проекта. Отдельный файл SQL `SrpskiLab-legacy-answer-bank-PRIVATE.sql` загружать на GitHub нельзя. Даже если GitHub приватный, хранить ответы отдельным локальным файлом надёжнее.

**Что ещё не готово:** 245 полноценных уроков A1–B2, новая SQL-миграция банка v3, лингвистическая экспертиза и реальные пользовательские испытания. Достижение B2 не подтверждается локальными тестами.
