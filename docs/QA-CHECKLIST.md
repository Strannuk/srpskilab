# Контрольный список перед открытием SrpskiLab другим пользователям

## Ручное тестирование (не выполнялось без твоего реального Supabase)

- [ ] `npm install`, `npm run typecheck`, `npm run test` и `npm run build` проходят на Windows.
- [ ] SQL-миграция `001` применена, сиды `002` применены, нет ошибок Postgres.
- [ ] Проверены регистрация, письмо подтверждения, вход, выход, восстановление, смена пароля.
- [ ] Аккаунт A не может через REST читать, писать и удалять записи аккаунта B.
- [ ] Нельзя отправить произвольный `completed=true` или `score=100` для подтверждения зачёта.
- [ ] После первого урока с 4/7 второй остаётся закрытым; с 5/7 открывается.
- [ ] Успешный урок не становится непройденным после ошибки следующей попытки.
- [ ] При скачке на URL урока N+2 обход блокировки невозможен.
- [ ] Граница уровня: экзамен 79% не разблокирует A1, 80% — разблокирует.
- [ ] Экзамен не откроется до успешных уроков уровня.
- [ ] Две вкладки и два устройства не удваивают счетчик попыток и не понижают лучший результат.
- [ ] После закрытия браузера/перехода на другом устройстве шаг урока и результаты сохранены.
- [ ] Нет сети: сохранение показывает «Ожидает синхронизации», следующий урок закрыт; при восстановлении сети запись отправлена 1 раз.
- [ ] Старый JSON v1 сохраняет историю, экзамены, словарь, карточки и не выдаёт фиктивный серверный зачёт.
- [ ] На Windows/Chrome, Android/Chrome, iOS/Safari MP3 воспроизводится, не требуется системный sr-RS, скорость/пауза работают.
- [ ] Послушаны вручную фонетически сложные пары č/ć, dž/đ, nj/lj, названия учреждений и имена, ударение/экавица.
- [ ] Файл manifest.json не помечается `approved`, пока носитель не проверил дорожки.
- [ ] Нельзя попасть на чужой профиль при быстром выходе из аккаунта A и входе в B.
- [ ] Edge Function удаления аккаунта опубликована, удаляет только своего пользователя с подтверждением.
- [ ] Прямой переход `/lesson/m1l1` после F5 на Vercel работает.
- [ ] Production SMTP и разрешённые redirect URL настроены.
- [ ] Бэкап Postgres создан, пробное восстановление выполнено отдельно от production.
- [ ] Коммерческие/публичные права на синтетические голоса и учебный контент проверены.
- [ ] Проведён педагогический аудит всех 265 уроков, в первую очередь B1–B2.

Техническая комплектность ≠ проверка на настоящих пользователях. Эти критерии требуют отдельной приёмки перед публичным релизом.
