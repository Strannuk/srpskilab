# SrpskiLab v3 — приложение для изучения сербского

React 19, TypeScript, Vite, Cloudflare Workers и Supabase. В исходном каталоге 31 модуль и 265 уроков; клиент включает авторизацию, последовательную разблокировку занятий, словарь, интервальное повторение и проигрывание записанного сербского аудио.

## Сначала прочти инструкции

- **[AUDIO-FIXES-AND-INSTALL-RU.md](AUDIO-FIXES-AND-INSTALL-RU.md)** — что исправлено в озвучке и тёмной теме, как проверить и обновить существующий GitHub/Cloudflare, что делать с Supabase.
- **[START-HERE-V3-RU.md](START-HERE-V3-RU.md)** — прежняя общая инструкция по серверным миграциям версии v3 (для новой установки; **не запускать повторно**, если уже применена).
- **[docs/course-v3/](docs/course-v3/)** — техническое задание и редакторские документы по учебным материалам.

## Локальный запуск (Windows, VS Code)

```powershell
npm ci
Copy-Item .env.example .env.local
# Если .env.local уже настроен, НЕ перезаписывай его.
# Впиши только публичные VITE_SUPABASE_URL и VITE_SUPABASE_PUBLISHABLE_KEY.
npm run typecheck
npm run audio:coverage
npm run smoke
npm run content:v3:verify
npm run test
npm run build
npm run dev
```

`http://localhost:5173` — локальный адрес. Изменения в коде **не требуют новых SQL**, если v3 уже правильно подключён к твоему Supabase.

## Подтверждённые ограничения

- Все 1865 текстов с кнопкой воспроизведения имеют путь к одному из 1835 технически проверенных MP3. **Озвучка синтетическая, произношение и условия лицензии не подтверждены преподавателем.**
- Первые 20 уроков A0 содержат расширенные черновики, другие 245 имеют дополнительные учебные материалы, но не прошли независимую языковую экспертизу и не заменяют полноценный курс до B2.
- Проверки живых логина/регистрации, Supabase и Cloudflare должны быть выполнены на доступной владельцу тестовой среде. Не публикуй незавершённый образовательный релиз широкой аудитории до проверки.

**Не помещай в GitHub:** `.env.local`, пароль базы данных, `service_role` / secret ключи, `supabase/private/`, приватный SQL правильных ответов.
