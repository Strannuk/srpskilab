# SrpskiLab v3 — исправленная озвучка и интерфейс (Windows / VS Code)

**Источник:** файл `SrpskiLab-v3-265-STUDY-EDITION.zip`, полученный ранее в этом чате, с действующей клиентской архитектурой React / TypeScript / Vite + Supabase + Cloudflare Workers. Это не чтение последней незагруженной локальной версии GitHub/VS Code.

## 1. Результат проверки и внесённые исправления

- **Кнопки динамика:** найдено 1865 различных сербских строк (словарь, карточки повторения, слова и примеры уроков, дополнительные примеры, новые диалоги, аудирование и кнопка тестового звука в настройках).
- **До исправления:** у 192 строк отсутствовала запись в `audio-index.json`; ещё 30 отличались от индексированных только регистром букв.
- **После исправления:** 1865/1865 получают путь `/audio/<id>.mp3`. Некоторые отсутствовавшие ссылки восстановлены к уже существовавшим файлам, 48 новых MP3 синтезированы локально. Общий набор содержит **1835 различных MP3**.
- Все 1835 файлов проверены локальным `ffprobe`: контейнеры MP3 читаются, длительность больше 0,12 сек. Фонетика eSpeak **не подтверждена** экспертом, акустическую корректность каждого звука тест MP3 не доказывает.
- `src/lib/audio.ts`: поиск записи нормализует пробелы, кириллицу/латиницу и регистр.
- `src/lib/voice.tsx`: поздняя ошибка одного аудиозапроса больше не сбивает состояние уже запущенной следующей записи; обработаны `play()` rejection и ошибки загрузки; системный голос используется только при наличии подлинного `sr`.
- `src/components/AudioButton.tsx`: при отказе проигрывания отображается ошибка **только на соответствующей кнопке**, остальные динамики не становятся ошибочными.
- `src/components/StudyUnit.css`: белая карточка с белым текстом в тёмной теме исправлена: `--paper` и `--ink` вместо отсутствующего `--surface`.
- Добавлены `scripts/ensure-audio-coverage.py` (генерация недостающего аудио) и `scripts/verify-audio-coverage.cjs` (проверка всех ссылок без внешних утилит), а также `scripts/smoke-without-vite.cjs` и `tests/audio.test.ts`.

**Не изменялись:** регистрация, Supabase-схема, SQL-функции, правильные ответы уроков, RLS, id уроков, прогресс, учебные тексты, аудиосистема на уровне подключения к базе. `audio-index.json`, `public/audio/manifest.json` и дополнительные MP3 входят в ZIP.

## 2. Установка на Windows в VS Code

1. Сделай копию своей рабочей папки и сохрани текущие `.env.local` и Git-историю.
2. Распакуй исправленный ZIP в **отдельную** папку, открой папку `srpskilab` с `package.json` в VS Code.
3. Скопируй в неё свой существующий `.env.local` с **публичными** переменными Supabase (не добавляй секретные ключи).
4. Открой **Terminal → New Terminal** и выполни:

```powershell
npm ci
npm run typecheck
npm run audio:coverage
npm run smoke
npm run content:v3:verify
npm run test
npm run build
npm run dev
```

Открой `http://localhost:5173`. В своём аккаунте проверь `/lesson/m1l1`, `/dictionary` и `/review`; включи тёмную тему в настройках и прослушай несколько проблемных ранее слов. Для сравнения проверь, например, `dan`, `more`, `beba`, `Dobar dan`, `ljudi`, фразы из раздела дополнительных примеров и любое слово в словаре.

**Если Windows сообщает о проблеме с Rollup/esbuild:** удали **только** локальную папку `node_modules`, затем ещё раз выполни `npm ci`. Не переносить `node_modules` из архива или с другой ОС. Работающие локально `.env.local` и файлы проекта при этом не удалять.

## 3. Что изменить в базе данных?

**Для этого исправления аудио и CSS — ничего.** Если три миграции v3 уже были корректно выполнены в том же проекте Supabase, повторять их не надо. В особенности **не запускай приватный банк ответов повторно** и не удаляй таблицы прогресса.

Если тесты самих уроков возвращают ошибку `new study bank not activated` или `function not found`, это **отдельная проблема версии Supabase**, а не озвучки. Проверь по инструкции `START-HERE-V3-RU.md` и в резервной копии БД, затем согласуй применимость SQL со своими фактическими данными.

Для безопасной первичной диагностики можно выполнить только `SELECT`:

```sql
SELECT study_content_version, count(*)
FROM public.course_lessons
GROUP BY study_content_version;
```

При ранее успешной активации v3 ожидается `study_content_version = 2` для 265 уроков. Этот запрос изменять данные не будет. Если столбца нет, установка v3 неполная: не выполняй миграции без проверки текущего состояния БД и резервного копирования.

## 4. Обновление уже работающего GitHub / Cloudflare

**Не заменяй `.git` и `.env.local`.** Перенеси файлы из ZIP в существующий рабочий репозиторий `srpskilab`, оставив `.git` и свой `.env.local`. Работай в новой ветке:

```powershell
git switch -c fix/audio-and-dark-theme
npm ci
npm run audio:coverage
npm run typecheck
npm run test
npm run build
git status
```

Только после успешной проверки и отсутствия секретов среди `git status`:

```powershell
git add .
git commit -m "fix: repair all Serbian audio links and dark theme"
git push -u origin fix/audio-and-dark-theme
```

Создай PR и выполни merge в `main`, если именно `main` подключена к автоматическому развёртыванию Workers. В Cloudflare Workers проверь **Build variables** (`VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`), дождись новой сборки и затем обнови сайт с `Ctrl + F5`.

## 5. Границы проверки

Подтверждены: TypeScript `tsc -b`, Node-проверка данных, ссылок на все 1865 озвучиваемых строк, формата всех 1835 MP3, логики блокировки уроков и преобразования письменностей через независимые smoke-тесты, а также SSR-рендеринга трёх основных компонентов для всех 265 уроков (795 рендеров).

Не удалось провести в этой Linux-среде: полную сборку Vite и запуск Vitest (в доступной **старой** копии `node_modules` отсутствует нативный пакет Linux Rollup, а доступа к npm registry нет), а также реальный браузерный E2E на твоём домене с твоими авторизационными данными. `npm ci` на Windows установит зависимости заново, и **эти проверки обязательны перед production-развёртыванием**. Нет независимой языковой/фонетической экспертизы, проверки лицензии звуков и проверки production Supabase.

**Важно:** проект остаётся учебной редакцией: 20 подробных A0-черновиков и 245 дополнительных материалов по старым лекциям. Заполненный каталог на 265 уроков не подтверждает самостоятельное освоение B2. Исправление воспроизведения не гарантирует корректное произношение каждого слова.
